# 🌱 Mini Garden Chatbot

## Deskripsi

Mini Garden Chatbot adalah aplikasi chatbot sederhana yang dibuat
untuk memberikan informasi mengenai berbagai jenis tanaman.

Aplikasi ini dibuat menggunakan bahasa pemrograman Python dan
library Streamlit.

Chatbot menggunakan database internal sederhana dan sistem
pencocokan kata kunci untuk memberikan jawaban kepada pengguna.

## Fitur

- Menampilkan data tanaman
- Mencari informasi tanaman
- Menampilkan jenis tanaman
- Menampilkan kebutuhan cahaya
- Menampilkan kebutuhan penyiraman
- Menampilkan manfaat tanaman
- Memberikan informasi cara perawatan
- Chatbot berbasis kata kunci
- Tampilan sederhana dan mudah digunakan

## Teknologi

- Python
- Streamlit
- GitHub
- Streamlit Community Cloud

## Struktur Proyek

```text
mini-garden/
├── app.py
├── requirements.txt
└── README.md
````

## Cara Menjalankan

Install library Streamlit:

```bash
pip install streamlit
```

Kemudian jalankan aplikasi:

```bash
streamlit run app.py
```

## Cara Menggunakan

1. Pilih tanaman pada bagian Data Tanaman.
2. Lihat informasi tanaman.
3. Masukkan pertanyaan pada bagian chatbot.
4. Klik tombol "Tanya Chatbot".
5. Chatbot akan memberikan jawaban berdasarkan database tanaman.

## Contoh Pertanyaan

* Cara merawat monstera?
* Berapa kali menyiram kaktus?
* Apa manfaat lidah buaya?
* Cahaya yang dibutuhkan lidah mertua?
* Tanaman apa yang cocok di dalam rumah?
* Tanaman apa yang mudah dirawat untuk pemula?
